# Sample Videos

Drop background video clips here (`.mp4`). These are picked up automatically by `bumper add` and `bumper assets`.

The main `videos/` directory at the project root works the same way — `bumper` searches both locations.

## What works well for bumpers

- **Ambient/looping clips**: rain on glass, fire, ocean waves, city at night, starfields
- **Abstract/slow motion**: smoke, water drops, bokeh lights, neon reflections
- **Low contrast scenes**: the text needs to be readable — avoid busy or high-contrast footage
- **Short loops** (5–30s): ffmpeg loops them automatically to fill the bumper duration

## Naming convention

Use lowercase kebab-case: `ocean-waves.mp4`, `rain-window.mp4`, `campfire.mp4`
